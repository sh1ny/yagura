# yagura_proto

Dart code generated from the yagura.v1 protocol in `proto/` (messages, enums, gRPC clients and service bases). Import `package:yagura_proto/yagura_proto.dart`.

`lib/src/generated/` is generated; do not edit it. Regenerate after changing any `.proto` file:

```sh
mise run proto
```

`tool/gen_proto.dart` uses `protoc` pinned in `mise.toml` and compiles the `protoc_plugin` version pinned in this package's `pubspec.yaml`.
