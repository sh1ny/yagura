# WinSW

`WinSW.NET461.exe` is [WinSW](https://github.com/winsw/winsw) 2.12.0, unmodified, from
<https://github.com/winsw/winsw/releases/download/v2.12.0/WinSW.NET461.exe>
(SHA-256 `b5066b7bbdfba1293e5d15cda3caaea88fbeab35bd5b38c41c913d492aadfc4f`).
It needs .NET Framework 4.6.1 or later, which every supported Windows version ships.
`yagurad service install` copies it to `%ProgramFiles%\Yagura\` as the service wrapper (ADR 0012).
