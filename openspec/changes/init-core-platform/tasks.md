# Tasks

## Test map

Every scenario maps to a Dart test at the boundary it crosses: daemon behaviour against an in-process daemon with fake SteamCMD, fake process host and fake firewall where the real one is not needed; process rows against the real OS on the Windows CI runner (`integration_test/`, tagged `windows`); desktop rows as Flutter widget tests against a fake daemon connection. Rows that need the real Valheim server are tagged `valheim`: they run on a Windows machine with Valheim installed (task 9.7), not on CI. The group column says which task group turns the row green; every group belongs to M1.
